# CGPA Goal Predictor 🎯

## Description
A web application that helps students determine the SGPA they need in future semesters to achieve a desired CGPA.

## Example
If a student has:
- Completed 4 semesters
- Current CGPA: 7.0
- Target CGPA: 8.0

The app calculates the SGPA required in remaining semesters.

## Features
- Target-based CGPA prediction
- Supports multiple semesters
- Easy input and instant calculation

## Tech Stack
- Python
- Flask
- HTML/CSS

## How it Works
Uses cumulative GPA formula to back-calculate required SGPA.
